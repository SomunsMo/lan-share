# i18n 国际化

## 架构

- 桌面端与 Web 端各自维护翻译文件，不共享
- 桌面端翻译: `src/locales/{zh-CN,en}.json`
- Web 端翻译: `src-web/src/locales/{zh-CN,en}.json`
- 库: `i18next` + `react-i18next`，初始化见 `src/i18n.ts`、`src-web/src/i18n.ts`
- 扩展语种: 新增 JSON 文件 + `i18n.ts` 的 `resources` 中追加，无需改组件结构

## 语言检测

- 桌面端: `invoke('get_language')` 读 SQLite `config` 表 `language` 键；无值 → `navigator.language` 以 `zh` 开头取 `zh-CN`，否则 `en`
- Web 端: `localStorage` key=`lan-share-language`；无值 → 同上系统检测
- 切换后 `changeLanguage()` 立即生效并持久化，不再跟随系统

## IPC

- `get_language` / `set_language` 定义于 `src-tauri/src/cmd/system.rs`，注册于 `src-tauri/src/cmd/_cmd_handler.rs`
- 桌面端语言初始化/切换后同步托盘文本: `invoke('update_tray_menu')`（见 `src/i18n.ts`）

## key 规范

- 命名: `模块.组件.含义`，动态参数用 `{{varName}}` 插值
- 增删 key 前 grep `src/ src-web/ src-tauri/` 确认无遗留引用

## 打包

- 桌面端: `import()` 懒加载 JSON（Vite chunk）
- Web 端: 静态 `import`，兼容 `vite-plugin-singlefile` 单文件打包
