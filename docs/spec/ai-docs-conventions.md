# AI 文档编写规范

## 职责

- AGENTS.md 管 AI 行为规则（每轮加载必须）
- docs/spec/ 管功能说明（按需查阅）

## 内容

- 每条文本兼顾 token 成本与精度：能用 5 字说清不用 10 字，但不可因省字产生歧义
- 每条描述须有代码证据，否则不写
- 引用文件路径 + 关键函数名
- 只写已实现的内容

## 格式

- 用 `- key: value` 紧凑列表，避免段落
- 每个文件保持 5–20 行
- 不写重复代码注释的内容

## 维护

- 改功能代码时同步更新关联 spec
- spec 与代码不符时立即修正
- AGENTS.md 修改须经用户审核
